# Exo 2 browser asset

KiMap uses one upright, unsubsetted Exo 2 variable font as a restrained Workbench display face.

- Source: `../Exo2-unreleased/Exo2-VariableFont_wght.ttf`
- Source SHA-256: `9FDF52B857862433836917BBFAF24C5835F38D6CB34B1FA830E155205A24CD5E`
- Output: `Exo2-VariableFont_wght.woff2`
- Output SHA-256: `AEC2E436A1B9AF12AA29EEE8553D56955C54F4E31FCF2F3551D322BBC18B9E03`
- Conversion: FontTools 4.63.0 with Brotli 1.2.0
- Variable axis: `wght`, 100 through 900, default 400
- License: SIL Open Font License 1.1; see `OFL.txt`

The font was converted without subsetting so the supplied character coverage remains intact. The
italic variable face and all static upright/italic faces are intentionally excluded from KiMap's
runtime assets because the Workbench currently uses only upright display typography.
